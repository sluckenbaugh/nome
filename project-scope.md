# Goal
Build a metronome browser app that is free to use and does not require authentication, signup, etc.

# MVP features
- Select a tempo for the metronome 
- Start and stop button
- a volume fader to control output volume
- Ability to add or remove accent clicks (a different audio sample from the normal click) from the metronome

# Advanced Features
- Give the user an interface to add or take away 'steps'. The interface can have 1 - 7 steps and users can mute certain steps or add accents.
- Ability to halve or double the tempo with a single button click
- Ability to detect a user's tap tempo from space bar presses.
- light and dark mode
